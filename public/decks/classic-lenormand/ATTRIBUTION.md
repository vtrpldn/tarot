# Classic Lenormand artwork

The 36 fronts are crops of Johann Kaspar Hechtel's *Das Spiel der Hofnung* (*The Game of Hope*, 1799), a 6×6 sheet whose printed, row-major numbers run from 1 to 36. It is the historical 36-symbol precursor to Petit Lenormand.

- Original archival sheet: <https://upload.wikimedia.org/wikipedia/commons/a/a6/Das_Spiel_der_Hofnung_%28The_Game_of_Hope%29.png>
- Source metadata and Public Domain Mark: <https://commons.wikimedia.org/wiki/File:Das_Spiel_der_Hofnung_(The_Game_of_Hope).png>
- Original dimensions: 3900×4900 PNG; Commons page id 92959998.
- License: Public Domain Mark 1.0 (the 1799 work is public domain).
- Physical card dimensions: 50×66 mm in the [British Museum record](https://www.britishmuseum.org/collection/object/P_1896-0501-495); generated canvases preserve that 25:33 aspect ratio.

`source/01-rider.jpg` through `source/36-cross.jpg` preserve the numbered cards and borders. The cropped mapping is row-major: 01–06, 07–12, 13–18, 19–24, 25–30, 31–36. Each is deskewed and centered without distortion on the same 610×860 period-paper canvas.

`source/back.jpg` is an original geometry-only back generated by `scripts/build-lenormand-assets.mjs`. Its muted paper, ink, diamond, and rosette pattern is period-inspired and does not reproduce any card front or third-party artwork.

The build script verifies the 3900×4900 source against the SHA-1 published by Commons. If the original-file CDN is throttled, it accepts only Commons' pixel-equivalent 3900 px renderer output, whose checksum is also pinned in the script.
